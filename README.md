# ルナネコの不思議な冒険

にゃんるな・つきねこ・オムソロ・もちにゃふぇが冒険する、スマホとPC向けの3Dブラウザアクションゲームです。Three.jsで描画し、物語・キャラ育成・装備・編成をブラウザ内に保存します。

**[ブラウザで遊ぶ](https://lunaneco.github.io/lunaneko-hunting/)** — スマホ・PC対応、インストール不要。

## ゲーム内容

- 本編は全3章・12幕・72WAVE。第1章で親友のつきねこと再会し、第2章「穂むすびの国」でオムソロ、第3章「もちにゃふぇの国」で最後の一匹を救出します。第2章クリア後は各章のエクストラ（各6WAVE）に挑戦できます。
- 最大2人の編成。魔法使いのにゃんるな、銃使いのつきねこ、光剣を使うオムソロ、援護特化のもちにゃふぇから選び、交代して操作します。各キャラに固有の必殺技があります。
- 左下の地図に現在地・敵・開いた出口を表示。通常の敵は赤い丸、ボス・強ボスは金色のひし形で、移動に追従し、撃破・フロア移動時に消えます。
- HPはキャラ別。操作していない仲間はダメージを受けません。操作中のキャラが倒れると生存する相方へ自動交代し、全員が倒れると終了。戦闘不能の仲間は援護せず、次の冒険で全回復します。
- キャラ別の経験値・レベル、基礎HP・攻撃・防御、2段階の能力成長ツリーとスキル解放の枝、アイテムを使う限界突破。
- クリスタルで選ぶ3択の祝福は、編成に応じて変わり、同じ幕の最後まで継続します。
- ステージミッション、付け替え可能なユニーク装備、通常／チャレンジモード。
- 異なる形のフィールド、2フロア、強敵のいる分岐。第2章は適正Lv.30で、専用の通常敵6種類とボス4種類が登場します。
- v1.35からキャラ・地形・攻撃範囲の表示倍率を固定。スマホの画面サイズ・縦横回転・ブラウザのバーの出入りでは見える範囲だけが変わり、キャラは拡大縮小されません。
- v1.18から撃破経験値を半減。既存の蓄積経験値・レベルを減らす変更はありません。

## 第3章・もちにゃふぇの国（v1.49）

第2章・第4幕クリア後に解放する全4幕・24WAVE。謎の敵の襲来で最後の一匹となったもちにゃふぇを、影爪・夢喰・黒鈴・闇の王の4体のダークもちにゃふぇから救います。言葉は「ふぇ〜」だけ。声、仕草、仲間の返事で、恐怖と信頼の変化を描きます。スライム、ゴブリン、スケルトン、オーク、ワーウルフ、ゴーレム、ドラゴンは、提供された「もちにゃふぇの不思議なダンジョン」のキャラクターを参考に3D化しました。

最後の月の門を通ると正式加入。既存の2人編成上限、キャラ別HP、旧セーブの成長やエクストラ解放を維持します。適正はLv.40、育成済みのにゃんるな・つきねこで4幕を自動戦闘クリアできることを検証しています。

- **援護**：4秒間隔で「ふぇ〜」の声を放ち、4体まで貫通。命中した雑魚を1.8秒停止し、詠唱・突進・設置予告を中断。ボスは移動を続け、5秒間の攻撃・防御30%低下を受けます。重複命中は時間更新で、倍率は累積しません。防御低下は敵の防御係数を下げ、受けるダメージを増やします。
- **育成**：援護を当ててから8秒以内に仲間が倒した敵でも、本人と撃破者それぞれに経験値。Lv.1はHP75・攻撃5・防御1の最弱キャラ。成長量はレベル進捗の3乗で増え、Lv.50ではツリーなしでもHP875・攻撃175・防御136。HP・防御のツリー成長3倍、攻撃成長2.5倍で、育て切ると4人で最高の基礎能力になります。
- **操作**：通常攻撃は小さな体当たり。序盤は遅く、短射程。Lv.50では間隔が1.4秒から0.35秒へ成長。援護停止効果は控えの声と必殺技に適用します。
- **必殺技**：「ふぇ〜・やさしい世界」。3回の範囲攻撃とHP36回復。雑魚を3秒停止、ボスの攻撃・防御を7秒間40%低下。専用の祝福6種類、成長ツリー、自然武器「もちもちの声」を使用。自然武器は固定で、既存3人の武器ガチャの確率は変えません。

提供された4本のMP3を複製・音量調整し、物語・戦闘に使用。戦闘は既存の-18.5 LUFS基準に補正してから50%の音量で再生します。新規TTSへの置き換えは行っていません。

提供モデルから法線・向き・接地を整えたGLBと透過立ち絵を制作。元のBlendファイルは変更していません。ゲーム用モデルは12,960三角形・4描画プリミティブ、glTFの上方向は+Y、正面は+Z。ゲーム内身長1.55単位、体の弾み・揺れ・声を出す動作はランタイムで付けます。実機性能の最終保証前のengine candidateです。背景4種は組み込みImageGenで生成し、モデルと音声は提供資料から制作しています。

検証：`npm test`、`node tests/chapter-three-browser-audit.mjs`。WebKitは`PLAYWRIGHT_BROWSERS_PATH=/tmp/lunaneko-playwright LUNARIA_BROWSER=webkit node tests/chapter-three-browser-audit.mjs`。ブラウザ監査は開発サーバー5185番ポートを使用します。

## エクストラステージ

第2章・第4幕の最後の月の門を通ると、第1章「月蝕の深淵」と第2章「穂守りの極陣」が同時に解放されます。すでに本編をクリアしたセーブでも解放。各章メニューの「エクストラ」から出撃できます。

どちらも全6WAVE・適正Lv.50・最高難度固定です。各章の敵6種類が最初から出現し、移動・弾速は1.25倍、攻撃の待ち時間の消化は1.65倍、予告時間は70%になります。出現間隔も短縮し、ボスはHP満タンから猛攻状態で戦います。敵のHP・攻撃力もLv.50の育成・装備を前提に強化。レベルによる出撃制限はありません。

ミッションはありません。各エクストラの初回クリア報酬は武器ガチャ券10枚、2回目以降は毎回2枚です。最後の月の門を通った時に支給し、初回受取はステージごとに保存します。途中帰還・敗北ではクリア報酬は支給されず、初回権利も残ります。敵・門の素材とボスの5%ガチャ券抽選は従来どおり別枠です。エクストラでは仲間加入・救出制限時間・章クリアの覚醒の輝石は発生しません。

Lv.50・成長ツリー育成済み・★4武器のにゃんるな／つきねこ編成で、両ステージの全WAVEと階段・月の門を通した自動戦闘を確認しています。

## スキル解放と付け替え（v1.42）

「メニュー・育成 → 成長ツリー → スキルの星」で、各キャラに3つの祝福候補を追加できます。Lv.5・15の星は★1素材、Lv.35の星は★2素材と「深星の扉」の解放が必要です。解放はキャラ別で、素材を一度だけ消費します。

出撃前に各キャラ3枠へ候補をセット。最初は従来の固有3種が設定されており、解放後の入れ替えは無料です。同じスキルが別の枠にある場合は枠を交換します。編成画面の「スキル候補を付け替える」からも移動できます。

| キャラ | 追加する候補 | 得意分野 |
| --- | --- | --- |
| にゃんるな | 月詠みの魔力・星結びの祝福・月影の結界 | スキル威力の増幅、祝福選択時の回復、敵の移動減速 |
| つきねこ | 貫く星弾・狙い澄ます一瞬・星銃の装填 | 通常弾の貫通、通常攻撃の会心、撃破時のゲージ獲得 |
| オムソロ | 翠刃の連舞・揺るがぬ守り・守り手の祈り | 斬撃の手数、被弾後の無敵時間、回復量 |

にゃんるなはスキルに最も優れた役割を維持。スキル威力1.5倍・必殺ゲージ獲得1.5倍に、新しい魔力増幅も重なります。「星結びの祝福」は1ランクにつき通常18HP、にゃんるな操作中は27HP回復。「月影の結界」は通常魔法の命中で2秒間の減速を与え、ボスへの減速量は半分です。

共通4種と二人の組み合わせ固有スキルは従来どおり自動で候補に入り、3枠を消費しません。解放やセットだけでは戦闘効果は発動せず、クリスタルを集めて3択で選んだときに発動します。選んだ効果は交代・フロア移動・月の門・つきねことの再会を通して同じ幕の全6WAVEで継続。次の出撃では効果をリセットし、候補の設定は保存します。既存の育成・所持品・クリア状況は引き継ぎます。

## BGM

v1.34からフィールドでは提供曲「LUNA field BGM (0.95x)」、ボス戦では「LUNA GAME BOSS BGM」をループ再生します。通常ボス・強ボスとも出現中はボス曲へ切り替え、撃破後はフィールド曲に戻ります。音源のテンポとステレオ音声を維持し、２曲の音量をそろえています。

ボイス中はBGMを下げ、一時停止・バックグラウンドでは再生を止め、再開時は続きから流します。設定のBGM OFFは効果音と独立。長い曲を一括デコードせずに再生し、オフライン用キャッシュは音声の部分読み込み・シークにも対応しています。

## キャラクターボイス

全3章・12幕の物語190台詞のうち、重要な場面ともちにゃふぇの声59台詞に音声を付けています。チュートリアル6台詞、戦闘用100件を含め、登録156件・実音声136ファイルです（もちにゃふぇの4本は場面ごとに再利用）。にゃんるなは指定の参照音声、つきねこはIrodori-TTSの声質指示で新しく生成した共通の基準音声、オムソロ・こむすびは役柄に合わせて選定した参照音声を使用。月の守護者とナレーションも話者ごとに同じ参照を使っています。

v1.47ではつきねこの被ダメージ音声を、柔らかく可愛らしい短い「いたっ！」へIrodori-TTSで作り直しました。同時に鳴る低い下降音の効果音も、つきねこだけ短い柔らかな音に変更。全戦闘ボイスの音量統一と50％の減衰は引き継いでいます。

v1.46ではつきねこの被弾時の短い掛け声「うっ！」を削除し、「これくらい！」だけを再生します。戦闘ボイス全80本の実測ラウドネスをもとに、再生時に−18.5 LUFSへ揃えてからゲインを50％（約−6 dB）に下げます。攻撃・被弾・交代・必殺技などに共通で適用し、ボイス音量設定はその上から反映。物語・チュートリアルの声やBGM・効果音の音量は維持します。

v1.45ではつきねこの全35本（物語8・戦闘27）をIrodori-TTS v4-Smallで再生成しました。柔らかく澄んだ中高音、前向きで一生懸命な話し方、喜びや驚きが素直に出る抑揚を指定。[赤血球役の演技についての出演者インタビュー](https://anime.eiga.com/news/111804/)を方向性の参考にし、声質は文章によるVoiceDesignで新しく設計しています。その生成音声を全台詞の共通参照にして、再会・励まし・戦闘・必殺技の演技を個別に指定。前回保持した祝福ボイスも含めて差し替え、表示台詞・発声場面・他キャラの音声は維持しています。MP3の音量・無音・読み・再生時間を確認し、内容ハッシュ付きURLで旧音声のキャッシュと区別します。

音声付きの場面は、各章の冒頭、リボンの約束、つきねことの再会と第1章の結末、オムソロの弱い声、救出直前・救出戦、親子の再会です。通常の移動や道中の会話はテキストとBGMで進行し、音声の再生ボタンも表示しません。第2章・第4幕の最後の加入説明もテキストのみで表示します。メニューから物語を読み返す場合も同じ構成です。

v1.28では、新しく指定された動画の声を参照し、にゃんるなの74本（物語41・チュートリアル6・戦闘27）をすべて再生成しました。再生成した音声には内容ごとに異なるURLを使い、以前の声がブラウザのキャッシュから再生されることを防ぎます。

v1.30では再会・救出場面の8台詞を再生成。にゃんるなの6台詞は合格済み会話も参照して声の高さを確認し、オムソロの2台詞は息継ぎと抑えた声量で瀕死の場面を演出しています。

v1.31では戦闘ボイス81本を参照音声・本編の会話と音響比較し、声のずれや短い発声で判定しにくかった38本を再生成しました。短い掛け声の声質・演技を音響数値だけで断定することはできません。

v1.33では第1章・第3幕の「ほどけても結び直せばいい」から始まるにゃんるなの台詞を、指定の参照音声と合格済みの会話を使って再生成。親友の言葉を思い出す間を取り、最後の「また会える」へつなぐ演技を指定しています。

v1.43では、用意されたつきねこの差し替え候補から35本（物語8・戦闘27）を採用しました。irodori-TTSの「ツキネコ」参照に合わせ、話者参照を強める設定（speaker K/V 1.5）で生成された音声です。配信するMP3をローカルのWhisper large-v3-turboで台詞照合し、声の高さ・参照声との近さ・音量・ピーク・前後の無音も再確認しました。既存音声と比べ、台詞ごとの声の高さの幅は8.7半音から3.6半音、参照声との話者埋め込み類似度は平均0.58から0.71へ改善。台詞間の類似度は0.86から0.85で、すべての指標が改善したという意味ではありません。参照との近さを優先して採用しています。自然な抑揚や演技の好みは機械評価だけでは断定できません。

新しい音声は48kHz・モノラルMP3で音量を統一し、全35本の再生時間を更新しました。内容ハッシュ付きのURLで旧音声のキャッシュ再生を防ぎます。ストーリーの台詞と音声を出す場面は変えず、必殺技の音声完了待ち・タップ省略・一時停止も検証しています。

v1.44では、ユーザーが基準に選んだつきねこの「この力、使いこなしてみせる！」をそのまま保持し、この音声を直接参照して他の34本（物語8・戦闘26）を再生成しました。ユーザーが選んだ試作Bの、弾む明るさを重視した演技に揃え、声量は普通で語尾は柔らかく指定。試聴したBの台詞も、その音声をそのまま採用しています。場面ごとに演技の指示を分け、生成用の句読点も調整しています。選定は複数候補の台詞照合と声質・音高の外れの検査によるもので、自然さや演技の好みを機械評価だけで保証するものではありません。表示台詞は維持し、音声URL・再生時間を更新しています。

## 専用武器とガチャ

各キャラには専用武器1枠と、全キャラ共通のユニーク装備1枠があります。同じユニーク装備は一人だけが使用し、メニューで仲間どうしの付け替えができます。

v1.36の装備一覧は入手済みのものだけを表示します。専用武器30種類（武器・レア度別）とユニーク装備10種類は、それぞれ1個ずつ同時に所持できます。付け替えや取り外しで所持品は失われません。「専用武器／ユニーク装備」の切り替え、現在の2枠と能力表示、折りたたみ式の性能比較で、スマホでも一覧をコンパクトに確認できます。

各幕の全6WAVEを終え、最後の月の門を通ると専用武器ガチャ券を毎回1枚確定で獲得。全8幕・両難易度・クリア済みの幕の周回にも適用されます。途中帰還や敗北ではクリア報酬はありません。さらに全章の通常ボス・強ボスを倒すと、1体につき5%で追加の券を1枚獲得。メニュー「武器ガチャ」で1枚の単発、または10枚の10連を選べます。券は獲得時に保存され、途中帰還・敗北でも残ります。3人の専用武器が各1/3で選ばれ、未加入キャラの武器も保管されます。

10連は単発と同じ割合で10回抽選し、10本を一覧表示します。同じ10連内で出た同一武器・同一レア度の重複も星の芽へ変換。券10枚の消費と全結果を演出前にまとめて保存するため、演出中の再読み込みでも結果は失われません。10連専用の「十星の月蝕召喚」では10個の星が集まり、月蝕が砕けて武器が順番に顕現。★4は一本ずつ、持ち主のキャラと武器のカットインで紹介します。青・紫・金の光は実際の獲得結果に対応し、タップで結果へスキップできます。前回の10連結果はガチャ画面にも表示し、結果一覧から装備の付け替えができます。演出軽減時は約1.35秒で結果を表示。10連演出は動画なしでも動き、画面を離れている間は進行を止めます。

## 強ボスルート

赤い門の強ボスは、同じ幕・同じ難易度の通常ボスに対してHPと全攻撃威力が2倍です。接触・突進・弾・魔法陣・ビームのすべてに適用。攻撃予告と回避の猶予は維持します。チャレンジモードでは通常ボスの1.3倍補正に重なり、冒険モードの通常ボス比で2.6倍になります。

Node.js 24推奨（最低22.12）。

```sh
npm ci
npm test
npm run build
npm run preview -- --port 4173
```

表示されたローカルURLを開いてください。Macでは `ゲームを起動.command` でも起動できます。`index.html` を直接開く方式ではありません。

## 保存と通信

アカウント登録、課金、外部API、広告・解析通信はありません。進行は、そのサイトを開いたブラウザのlocalStorageに保存します。保存先が異なるため、localhostと公開サイトでセーブデータは自動共有されません。公開サイトでは初回は新しい冒険として始まります。

HTTPSまたはlocalhostで初回の読み込みが完了すると、Service Workerがゲームファイルを保存し、以後はオフラインでも起動できます。セーブデータはクラウドへ送信しません。
